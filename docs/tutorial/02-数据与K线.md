# 02 · 数据与 K 线

数据是量化的地基。地基歪了，上面盖什么都是错的。本篇讲清楚：我们手里的数据是什么、怎么取、以及几个新手必须知道的坑。

对应代码：`quant/data/loader.py`

---

## 1. K 线与 OHLCV

我们用的是**日线**数据：一天一根 K 线。每根 K 线由 5 个数字描述（OHLCV）：

| 字段 | 含义 |
|------|------|
| `open` 开盘价 | 当天第一笔成交价 |
| `high` 最高价 | 当天最高成交价 |
| `low` 最低价 | 当天最低成交价 |
| `close` 收盘价 | 当天最后一笔成交价 |
| `volume` 成交量 | 当天成交的股数/手数 |

在本框架里，所有数据都被标准化成这 5 列、并以**交易日**为索引（升序）：

```python
from quant.data import get_daily

df = get_daily("000001", start="20200101", end="20231231")
print(df.head())
#               open   high    low  close      volume
# date
# 2020-01-02   16.65  16.95  16.55  16.87  1,530,231...
```

> 为什么大多数策略主要用 `close`？因为收盘价是当天市场博弈的"结论价"，
> 最有代表性。但要注意：**你在某天收盘时才知道当天 close，所以不能用今天的
> close 当作今天就能成交的价格**——这正是回测最容易作弊的地方（教程 04 详解）。

## 2. 复权：为什么不能用原始价格

股票会分红、送股、配股。在"除权除息日"，股价会**人为地跳一下**——这不是真实的涨跌，是把分红/送股的价值从股价里扣出去。

举例：某股 10 元，每股分红 1 元。除息日股价会"跌"到约 9 元，但你手里多了 1 元现金，**财富没变**。可如果直接用原始价格算收益或均线，程序会误以为"暴跌 10%"。

解决办法是**复权**：

- **前复权（qfq）**：以当前价格为基准，把历史价格往下调整，使价格序列连续。
  → 适合算技术指标、做回测（本框架默认）。
- **后复权（hfq）**：以最早价格为基准，把后面价格往上调整。
  → 适合算长期累计真实收益率。
- **不复权**：原始价格，除权日有跳变。→ 一般不用于回测。

`get_daily(..., adjust="qfq")` 默认就是前复权，你不用操心。

> 📖 **一个容易被忽略的细节**（来自 [AKShare 官方文档](https://akshare.akfamily.xyz/data/stock/stock.html)）：
> 前复权的历史价格会**随每次新的分红送股被重新调整**——即同一个历史日期的前复权价，
> 今天算和下个月算可能不一样。后复权价历史不变、更能反映长期真实收益，所以**量化研究中
> 后复权(hfq)也很常用**。本框架默认 `qfq`（更直观），做长期收益研究时可考虑 `hfq`。
> 完整权威出处见 [`08-参考资料.md`](08-参考资料.md)。

## 3. 数据从哪来：akshare + 本地缓存

我们用 [akshare](https://akshare.akfamily.xyz/) 拉数据，它免费、免注册，背后是公开的财经网页接口。

核心函数（`loader.py`）：

```python
def get_daily(symbol, start="20190101", end=None, adjust="qfq", use_cache=True):
    ...
```

- `symbol`：6 位代码，如 `"600519"`（茅台）、`"000001"`（平安银行），不用加 sh/sz 前缀。
- 第一次调用会联网拉取，并把结果存成 `data/cache/{symbol}_{adjust}.parquet`。
- 之后再调用就**直接读本地缓存**，又快又稳，不会反复打网络被限流。

> 想强制重新拉取？删掉缓存即可：
> ```python
> from quant.data import clear_cache
> clear_cache("000001")     # 清某只；clear_cache() 清全部
> ```

> 网络小贴士：国内网络/代理环境下，数据接口常间歇性断连（`ProxyError`/
> `ConnectionError`）。`loader.py` 已内置三重容错：**绕过代理直连 + 自动重试 +
> 东方财富/新浪双源切换**，所以你通常不用管。万一两个源都暂时连不上，
> 稍等几分钟重跑即可；一旦缓存成功，后续就不再依赖网络了。

## 4. A 股交易规则（数据之外的"游戏规则"）

光有价格还不够，回测必须知道 A 股的规则，否则会高估收益。这些规则在
`quant/backtest/broker.py` 里实现，这里先认识它们：

1. **T+1**：今天买入的股票，当天不能卖，次日才能卖。
2. **涨跌停**：主板 ±10%；创业板/科创板 ±20%（新股上市前 5 个交易日不设限）；ST 股 ±5%。一字涨停买不进、一字跌停卖不出。
3. **手续费**：佣金（券商自定，常见万 2.5~万 3，单笔最低 5 元，买卖双向）+ 印花税（**仅卖出**，0.05%）。
4. **整手**：买入按 100 股的整数倍。

> 📖 **权威出处**（详见 [`08-参考资料.md`](08-参考资料.md)）：
> 涨跌幅与 T+1 见[深交所/上交所交易规则](http://www.szse.cn/)；印花税税率见
> [财政部 税务总局公告 2023 年第 39 号](http://www.news.cn/fortune/2023-08/27/c_1129826990.htm)
> ——自 **2023-08-28** 起由 0.1% 减半为 **0.05%**（出让方单边）。规则会变，以官方最新为准。

> 这解释了教程 00 里那个"坑"：贵州茅台一手要 15 万+，10 万本金买不起一手，
> 策略会长期空仓。**标的选择本身就是策略的一部分。**
