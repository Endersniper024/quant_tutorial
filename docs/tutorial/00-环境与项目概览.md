# 00 · 环境搭建与项目概览

欢迎入门量化！这份教程会带你**边跑代码边理解原理**。读完整个系列，你应该能独立写一个策略并正确回测它。

本篇目标：把环境装好，跑通第一个例子，建立全局认知。

---

## 1. 先跑起来，再理解

学量化最忌讳"光看不练"。我们先让程序跑起来，看到结果，再回头讲为什么。

### 安装环境

本项目用独立的 conda 环境（不污染你的 base 环境）：

```bash
conda create -n quant python=3.12 -y
conda activate quant
pip install -r requirements.txt
```

依赖很少：
- `akshare`：免费获取 A 股行情（无需注册/token）
- `pandas` / `numpy`：数据处理与计算
- `matplotlib`：画图
- `pyarrow`：存取 parquet 缓存文件

### 跑通第一个例子

```bash
python examples/run_ma_cross.py
```

第一次运行会联网拉数据（之后读本地缓存，秒开）。你会看到类似输出：

```
起始资金    : 100,000.00 元
期末资金    : 65,222.10 元
累计收益率   : -34.78%
...
图已保存到：output/000001_ma_cross.png
```

打开那张图，你会看到一条资金曲线和买卖点。

> ⚠️ 别被"亏了 34%"吓到——这恰恰是本教程的第一个重要结论：
> **一个听起来很合理的简单策略，加上真实交易成本，长期很可能是亏钱的。**
> 我们学量化，正是为了用数据严格地检验"听起来合理"的想法。

> 💡 Windows 小坑：如果你用 `conda run -n quant python ...` 遇到中文乱码报错，
> 改成先 `conda activate quant` 再 `python ...` 就好。

## 2. 这个项目在做什么

量化研究的核心是一条闭环：

```
   数据  →  策略  →  回测  →  评估  →  改进
   ↑                                    │
   └────────────────────────────────────┘
```

- **数据**：拿到干净、可信的历史行情（`quant/data/`）
- **策略**：把"什么时候买、什么时候卖"写成代码（`quant/strategy/`）
- **回测**：在历史数据上模拟执行这个策略，看会发生什么（`quant/backtest/`）
- **评估**：用客观指标判断好坏，而不是凭感觉（`quant/analysis/`）
- **改进**：根据评估结果调整，再来一轮

这个项目就是把这条闭环的每一环都用最小、最清晰的代码实现出来。

## 3. 代码地图

```
quant/
├── data/loader.py        ← 数据从哪来（akshare + 本地缓存）
├── strategy/
│   ├── base.py           ← 策略长什么样（基类/接口）
│   └── ma_cross.py       ← 一个具体策略（双均线）
├── backtest/
│   ├── account.py        ← 钱和持仓怎么记账（含 T+1）
│   ├── broker.py         ← 订单怎么成交（含 A 股规则）
│   └── engine.py         ← 把上面串起来的主循环 ★核心★
└── analysis/
    ├── metrics.py        ← 怎么算收益/风险指标
    └── plot.py           ← 怎么画图
```

建议的阅读顺序就是教程的顺序：先懂数据，再懂策略，最后啃回测引擎。
