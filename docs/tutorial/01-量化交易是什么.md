# 01 · 量化交易是什么

本篇不写代码，只建立认知。认知错了，后面写再多代码都是白费。

---

## 1. 一句话定义

**量化交易 = 用明确的、可被计算机执行的规则来做交易决策。**

关键词是"明确的规则"。区别在于：

| | 主观交易 | 量化交易 |
|---|---|---|
| 决策依据 | 看盘感觉、新闻、经验 | 写死的规则 / 模型 |
| 能否复现 | 难，依赖人的状态 | 完全可复现 |
| 能否检验 | 难，事后找理由 | 可在历史数据上回测 |
| 能否规模化 | 一个人盯几只 | 程序同时盯几千只 |
| 最大敌人 | 情绪 | 过拟合（见教程 06） |

量化最大的价值不是"用了高深算法"，而是**把模糊的直觉变成可以被严格检验的规则**。

---

## 2. 一个完整的量化研究流程

```
①提出想法 → ②拿数据 → ③写成策略 → ④回测 → ⑤评估 → ⑥改进/淘汰 →（实盘）
```

1. **提出想法（假设）**：比如"短期均线上穿长期均线后股价会继续涨"。
2. **拿数据**：获取相关的历史行情。
3. **写成策略**：把想法翻译成"什么条件下买/卖"的代码。
4. **回测**：在历史上模拟跑一遍，看会怎样。
5. **评估**：用收益、回撤、夏普等指标客观判断。
6. **改进或淘汰**：好就优化，差就果断放弃，记下为什么失败。
7. **实盘**：只有经得起反复检验的，才考虑接真实资金（本项目第一阶段不涉及）。

本框架覆盖的就是 ②~⑤ 这段**研究回测闭环**。

---

## 3. 量化能做什么、不能做什么

### 能做
- 把一个想法**快速、客观地证伪**（大多数想法都会被证伪，这是好事）
- 同时监控大量标的，捕捉人盯不过来的机会
- 严格控制风险（仓位、止损都能写成规则）
- 消除情绪干扰，纪律性执行

### 不能做
- **不能预测未来**。回测好不代表未来赚钱。
- **不能保证盈利**。市场会变，规则会失效。
- **不能替你承担风险**。决策是你的，亏的是你的钱。
- **不能靠"过拟合"出来的漂亮回测赚钱**（这是新手头号死因，见教程 06）。

> 记住：**回测是一面照妖镜，用来淘汰坏想法，而不是用来证明你能发财。**
> 一个新手最该养成的习惯是：对漂亮的回测结果保持怀疑。

---

## 4. A 股新手要特别注意的几件事

A 股和美股/加密的玩法差别很大，回测时必须考虑（教程 02、04 会落到代码）：

- **T+1**：今天买的，明天才能卖。
- **涨跌停**：普通股一天最多涨/跌 10%（创业板/科创板 20%，ST 股 5%）。一字涨停你买不进，一字跌停你卖不出。
- **交易成本**：佣金（万 2.5~万 3，单笔最低 5 元）+ 卖出印花税（0.05%）。别小看，高频交易会被成本吃光。
- **整手**：买入必须是 100 股的整数倍。

很多"回测赚翻了"的策略，一旦如实加上这些规则和成本，立刻原形毕露。本框架默认就把它们考虑进去了。
