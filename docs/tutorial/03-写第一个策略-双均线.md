# 03 · 写第一个策略：双均线

本篇把"均线"变成可执行的买卖规则，写出（其实是读懂）你的第一个策略。

对应代码：`quant/strategy/base.py`、`quant/strategy/ma_cross.py`

---

## 1. 什么是均线（MA）

**移动平均线（Moving Average）= 最近 N 天收盘价的平均值。**

```python
ma20 = df["close"].rolling(20).mean()
```

它的作用是**抹平噪声、看清趋势**：
- 5 日均线（快线）：反应快，贴着价格走。
- 20 日均线（慢线）：反应慢，代表中期趋势。

直觉：当快线在慢线上方，说明近期价格比中期均值更强，趋势偏多。

---

## 2. 金叉与死叉

把快慢两条线画在一起，它们会交叉：

- **金叉**：快线**上穿**慢线（昨天还在下面，今天到了上面）→ 趋势转强 → **买入信号**。
- **死叉**：快线**下穿**慢线 → 趋势转弱 → **卖出信号**。

注意"穿越"是看**相邻两天的相对关系变化**，不是看某一天谁高谁低。判断方式：

```python
golden_cross = fast_prev <= slow_prev and fast_now > slow_now   # 昨天下方/持平，今天上方
death_cross  = fast_prev >= slow_prev and fast_now < slow_now   # 昨天上方/持平，今天下方
```

## 3. 策略要实现的接口

所有策略都继承 `Strategy`（`base.py`），至少实现一个方法：

```python
class Strategy(ABC):
    def on_start(self, ctx): ...     # 回测开始调用一次（可选）
    def on_bar(self, ctx): ...       # 每根 K 线调用一次（必须实现）
    def on_finish(self, ctx): ...    # 回测结束调用一次（可选）
```

`on_bar(ctx)` 是核心。`ctx`（上下文）让你既能**读**信息又能**下单**：

读信息（都是只读的）：
- `ctx.history` —— 截止当前 bar 的历史 DataFrame（**看不到未来！**）
- `ctx.close` —— 当前 bar 收盘价
- `ctx.position` —— 当前持仓股数
- `ctx.available` —— 当前可卖股数（T+1：今天买的不算）
- `ctx.cash` —— 可用现金

下单（只是排队，下一根 bar 开盘成交）：
- `ctx.buy(shares)` —— 买指定股数（自动取整到 100）
- `ctx.buy_pct(pct)` —— 用总资产的 pct 比例买入（如 `0.95`）
- `ctx.sell(shares)` —— 卖指定股数
- `ctx.sell_all()` —— 清仓

> 🔑 最重要的一条：`ctx.history` 只给你截止当前的数据。你**没有办法**读到未来，
> 框架从机制上堵死了"用明天数据做今天决策"的作弊。这是回测可信的前提。

## 4. 完整策略代码

`ma_cross.py` 全文（已加注释）：

```python
class MaCrossStrategy(Strategy):
    def __init__(self, fast=5, slow=20, buy_pct=0.95):
        self.fast, self.slow, self.buy_pct = fast, slow, buy_pct

    def on_bar(self, ctx):
        closes = ctx.history["close"]
        if len(closes) < self.slow + 1:      # 数据不够算慢线+上一根，先跳过
            return

        fast_ma = closes.rolling(self.fast).mean()
        slow_ma = closes.rolling(self.slow).mean()

        fast_prev, fast_now = fast_ma.iloc[-2], fast_ma.iloc[-1]
        slow_prev, slow_now = slow_ma.iloc[-2], slow_ma.iloc[-1]

        golden_cross = fast_prev <= slow_prev and fast_now > slow_now
        death_cross  = fast_prev >= slow_prev and fast_now < slow_now

        if golden_cross and ctx.position == 0:
            ctx.buy_pct(self.buy_pct)        # 空仓 + 金叉 → 买入
        elif death_cross and ctx.available > 0:
            ctx.sell_all()                   # 有可卖持仓 + 死叉 → 清仓
```

逻辑就三步：**算两条均线 → 判断金叉/死叉 → 满足条件就下单**。

## 6. 它为什么会亏钱？（重要）

跑出来大概率是亏的。原因正是这个策略的**固有缺陷**，值得记住：

1. **震荡市反复挨打**：股价横盘小幅波动时，均线会频繁金叉死叉，每次买在小高点、卖在小低点，来回亏。
2. **信号滞后**：均线是平均值，天然慢半拍，等它发出信号，行情常常走了一半。
3. **成本侵蚀**：每次买卖都付佣金+印花税，交易越频繁，被成本吃得越多。

这不是 bug，而是双均线策略的本质。它的意义在于：**让你亲眼看到"一个直觉上合理的规则"如何被数据证伪**。这正是量化研究的日常。
