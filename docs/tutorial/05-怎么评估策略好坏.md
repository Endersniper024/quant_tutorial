# 05 · 怎么评估策略好坏

回测跑完，控制台吐出一堆数字。本篇教你看懂它们，并避免"只看收益率"的新手陷阱。

对应代码：`quant/analysis/metrics.py`

---

## 1. 只看收益率是不够的

两个策略都赚了 30%，但：
- A：稳稳地涨，中途最多回撤 5%。
- B：先翻倍再腰斩再回来，中途回撤 60%。

收益一样，但 B 几乎没人拿得住——大多数人会在回撤 60% 时崩溃割肉。
所以评估策略必须**同时看收益和风险**。

---

## 2. 六个核心指标

`compute_metrics(result)` 会算出这些：

### 累计收益率
整段时间总共赚了百分之多少。`期末资金 / 起始资金 - 1`。最直观，但忽略了时间长短和风险。

### 年化收益率
把累计收益折算成"每年"的速度，方便横向比较（和存款、和别的策略）。
```python
annual_return = (1 + total_return) ** (252 / 天数) - 1
```
（252 是一年约定的交易日数。）

### 年化波动率
收益的颠簸程度 = 日收益标准差 × √252。越大越刺激也越危险。

### 夏普比率（最重要的综合指标之一）
**每承担一单位波动，换来多少收益**：
```python
sharpe = 日收益均值 / 日收益标准差 × √252
```
经验参考（回测里要打折看）：
- < 0：还不如不做
- 0 ~ 1：一般
- 1 ~ 2：还不错
- \> 2：很好，但要高度警惕过拟合

> 📖 夏普比率的权威定义见 William F. Sharpe, *"The Sharpe Ratio"* (JPM, 1994)。
> 更要紧的是：如果你**试了几百个策略/参数，挑出夏普最高的那个**，这个夏普会被系统性高估——
> 这正是 Bailey & López de Prado 提出 **Deflated Sharpe Ratio（去偏夏普比率）** 要修正的问题。
> 论文链接见 [`08-参考资料.md`](08-参考资料.md)。这也是为什么上面写"回测里要打折看"。

### 最大回撤（Max Drawdown）
从某个高点跌到之后最低点的**最大跌幅**，衡量"最难熬时有多惨"：
```python
drawdown = 净值 / 历史最高净值 - 1
max_drawdown = drawdown.min()      # 负数，如 -0.56 表示最多跌过 56%
```
这是衡量"能不能拿得住"的关键。回撤 56% 意味着 100 万一度只剩 44 万。

### 胜率
完整买卖回合里赚钱的比例。**注意：高胜率 ≠ 赚钱！**
一个策略可以"赢 9 次各赚 1 块，输 1 次亏 20 块"，胜率 90% 却是亏的。
所以胜率要和"盈亏比"一起看。

## 3. 看我们的示例

平安银行双均线（教程 00 跑出来的）：

```
累计收益率   : -34.78%      ← 亏了三成多
年化收益率   : -8.49%
年化波动率   : +24.10%      ← 挺颠
夏普比率    : -0.25         ← 负的，不如不做
最大回撤    : -55.95%       ← 一度腰斩，根本拿不住
交易回合数   : 33
胜率      : +39.39%         ← 赢的次数还没一半
```

结论一目了然：**这个策略不行**。但这正是它的教学价值——你学会了用一套客观指标，
冷静地判一个策略"死刑"，而不是凭"它有时候也赚钱"自我安慰。

`plot_result(result)` 画两张图（见 `output/*.png`）：

- **上图：资金曲线 + 买卖点**。整体向右上=赚钱；红三角=买入，绿三角=卖出。
  和那条灰色虚线（起始资金）比，在上面才是赚的。

学会先看回撤图：**很多收益不错但回撤吓人的策略，现实中根本拿不住。**

---

## 5. 评估的正确心态

- 不要只盯收益，先看回撤和夏普。
- 对漂亮结果保持怀疑——越漂亮越可能是过拟合（下一篇）。
- 和"基准"比：如果策略还跑不赢"一直持有不动"，那它没创造价值。
- 单一标的、单一时间段的好结果**不算数**，要换标的、换时段反复验证。
